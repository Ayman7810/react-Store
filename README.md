# 🛍️ React Store – Simple E-Commerce Platform  

## 🌟 Overview  
**React Store** is a user-friendly e-commerce platform designed to provide a smooth shopping experience. It includes essential pages for managing products and users efficiently.  

### 🔥 Key Features  
- **Login Page** – Secure and fast user authentication.  
- **Sign-Up Page** – Allows users to create new accounts effortlessly.  
- **Home Page** – Displays featured and newly added products.  
- **Product Listing Page** – Browse all available products easily.  
- **Admin Dashboard** – Manage orders, products, and users efficiently.  
- **User Dashboard** – Track orders, save favorite products, and edit personal details.  

### 🛠️ Technologies Used  
- **Bootstrap** – Ensures a responsive and stylish design across all devices.  
- **React** – Creates a dynamic and seamless user experience.
